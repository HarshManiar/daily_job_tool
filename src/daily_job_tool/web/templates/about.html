About

Daily Job Tool is a personal job-matching tool for one person. It reads only publicly posted jobs, straight from employers' career pages and public job boards, and ranks them against one person's search.

  • It respects each site's robots.txt and skips anything a site asks automated tools not to read. Those employers are listed on Check these by hand.
  • Every job links out to the employer to apply. Applications never go through this tool.
  • It runs only on one computer and is not reachable from the internet. Nothing is published or shared.
  • Employers can ask to be removed: see Request removal and DailyJobToolBot.
