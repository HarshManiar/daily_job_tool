Privacy

The tool keeps its data in a database on the owner's own computer.

  • It stores public job data (titles, companies, locations, descriptions, links) plus the owner's saved searches, "checked" marks and last-visit time.
  • No accounts, no cookies, no analytics or tracking.
  • This web page makes no requests to any third party: no external fonts, scripts or images.
  • It does not collect personal data about recruiters or employees.

Deleting everything

Drop the daily_job_tool PostgreSQL database (for example dropdb daily_job_tool) and delete the project folder, the ~/.daily_job_tool folder and the backups in ~/Backups/daily_job_tool. To delete just the personal parts, delete your saved searches on the matches page.
